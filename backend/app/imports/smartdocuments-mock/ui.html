Make the mock fail, to test how the plugin and your process handle SmartDocuments errors. Applies to both endpoints.

SmartDocuments loses line breaks in JSON values, and in XML values without xml:space="preserve". Turn this off to always keep them.

How to use

  1. The SmartDocuments (Autodeployed) plugin configuration in the example app points to this mock.
  2. Start an Example case. The process calls get-template-names and generate-document.
  3. The requests appear in the Requests tab, with the template data and a preview of each generated format.
  4. The generated document is stored in the Documenten API. Open it in the Documents tab of the case.
  5. Set Payload format to XML in the generate-document action to keep line breaks in text values. The Requests tab shows which values kept or lost their line breaks.
  6. Change the letters in the Templates tab. Use {{key}} for a template data value.

Template edits are saved in imports/smartdocuments-mock/data/, which git ignores.
