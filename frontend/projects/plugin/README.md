# @valtimo-plugins/smartdocuments (Valtimo 12)

The frontend library of the SmartDocuments plugin for GZAC/Valtimo.

**This build is for Valtimo 12** (Angular 17, `@valtimo/*` 12.x). The Valtimo 12 versions end in `-V12` and are published
under the npm tag `v12`. Install the exact version:

```shell
npm i @valtimo-plugins/smartdocuments@1.1.0-V12
```

For Valtimo 13, use the version without `-V12` (`npm i @valtimo-plugins/smartdocuments@1.1.0`).

See the [plugin documentation](https://github.com/generiekzaakafhandelcomponent/smart-documents-plugin/blob/v12/documentation/plugin.md)
and the [compatibility table](https://github.com/generiekzaakafhandelcomponent/smart-documents-plugin/blob/v12/README.md#compatibility).
